Rules. A panel is --pane #1c1f26. If it is a column of the page it carries one hairline on the edge it meets the page at and no radius; if it is a card inside the page it carries a hairline all the way round and 8px corners. Rows inside a panel are 6px, chips and step rows 4px. A row has no ground until you touch it: hover is #242832 and nothing else moves. The selected row is the same amber on #14161a as an on button, at 600 — one selection colour for the whole app, so "chosen" never has to be learned twice. Labels above a block are 10px uppercase at .08em in --dim; the hand labels are the one place a label is coloured, and it takes the colour the notation already uses for that hand.
