Numbers in the foreground colour, the headline percentage green or red; the legend is pushed to the far end and names the three colours the roll uses.

Rules: green is --hit and every failure is the same #7a3a3d border with #ffb0b0 type — a miss is never the accent. The meter is built once per challenge and only mutated after that, because it repaints forty times a second under a playhead, so nothing in it may change size: the slots share the row, the bar is always 5 px, and the value is mono and tabular so 8% and 89% occupy the same width. A pass card is a fixed box for the same reason — height:20px;min-width:34px and an inline-flex centre, with the row itself centring them — so a row of passes is a row of equal cards and nothing shifts as one lands.
