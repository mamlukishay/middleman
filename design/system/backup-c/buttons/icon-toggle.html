Icon toggle

One glyph instead of a word — the melody's speaker. It is the same block as every other: the same tokens, the same 5 px of side, the same grain, the same instant drop and the same 2 px corner. .round is the theme's name, not its shape — it used to be a circle, and one circle among the blocks read as a different machine. What the class actually does is square the block off to its own face height, so a row of icons is a row of equal keys.

The same button inside #bar — 58 × 58
In the bar the square grows to the transport's, 58 × 58, and the glyph with it (15 px → 17). Nothing else about it changes, and it is exactly as wide as the toggle beside it — which is the point of squaring it off in the first place.

Rules. An icon toggle is a block first and an icon second: it never becomes a bare glyph on the panel. .round is a theme, not a shape and not a size — any icon-only button can take it, and .tgl.round then gets the lit and pressed states for free. It is a 29 px square on a panel and a 58 px one in a bar, because the bar sizes every block it holds. .na is not disabled: a disabled control is pushed in and painted a shade off the panel, saying "already down and not coming back", while .na stays lit amber because the setting really is on — it is only this moment that cannot honour it. Strike-through at 45% says "on, but not now"; press it and the setting still changes.
