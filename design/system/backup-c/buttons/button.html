Block button

The regular control on a laptop page. Off it is a block standing 5px proud of the panel; on it has travelled the whole 5px and is flush. Only box-shadow and a transform move, so a toggle can never shift the row it is in.

In a transport bar — the bar takes over the sizing
Inside #bar the same .tgl is the transport's square, 58 × 58: Wait for me wraps onto two lines inside the block instead of stretching it, and the ♪ is the same square rather than the 29 px one it is everywhere else. Nothing else changes — same face, same 5 px of side, same amber when it is down.

Rules. Every shadow has 0 blur: the edges are cut, not lit. The four borders are not one outline — the top catches the light (#5b6479), the sides are #3f4757, the bottom is where the face turns into the side (#191d25). Corners are 2px. Hover files the top edge brighter and changes the face by one stop; it never lifts the block, because the block is already up. A block has only two heights, so a control you cannot press is not flattened onto the panel — that read as neither in nor out — it is pushed all the way in like a lit toggle and then painted a shade off the panel with dim text: the geometry says "already down", the colour says "and not coming back". Colour eases 60ms, position never eases, and under prefers-reduced-motion nothing eases. Size is the only difference between regular and mini: same depth, same corners, same grain. And size is the one thing the bar decides: inside #bar every block is sized to the transport's square, 58 × 58, with its label wrapping inside it; everywhere else a block is one face, --btn-h 29 px, and as wide as its word.
