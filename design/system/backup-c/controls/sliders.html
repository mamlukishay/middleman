A level is not a slider. The native range input is still there and is still the value — every app reads and writes input.value — but it is display:none and what you see is a milled scale: twelve notches, every third one tall so the eye can count in threes without reading, lit up to the value in the accent. A click or a drag along the scale sets the input and fires its input event, so nothing downstream knows the slider went away. The number stays typable: it is the one reading you can also edit, and it takes an outline rather than a border so the pocket does not shift under it. The key beside the value (speed, vol, bpm) is engraved into the panel, not lit by it — only numbers carry light.
