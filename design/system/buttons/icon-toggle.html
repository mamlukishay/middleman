Icon toggle

The bar has exactly two one-glyph controls. .tgl.icon is the ordinary button squeezed to a single character — the melody-sound toggle on the practice page — and #inled is the MIDI-in lamp, which is not a button at all and never invites a click.

.tgl.icon — the base toggle at one glyph wide
offthe base face #2a2f3a on --line; only the padding changes, to 6px 9px, and the glyph goes up to 15px
hoverface #333947, the same change a word button makes
.onamber ground and border, ink #14161a, weight 600 — and no hover left, because .tgl.on outranks button:hover
disabledopacity .45, cursor default. The practice page keeps it hidden instead, until a melody is on screen
The square, against the word button it sits next to
one height16px line box + 6px + 6px padding + 2px border = 30px, for both
one on-statethe same amber, the same 600, at both widths
Square by arithmetic, not by declaration. Nothing sets a width or a height: 9px of padding either side of a 15px glyph lands the box at roughly the 30px the line box and vertical padding already give it. That is why the toggle reads as a square tile beside the word buttons rather than as a cropped one — and why the glyph has to stay a single narrow character.
#inled — the other one-glyph thing in the bar, and not a control
idle9×9, border-radius 50%, #3a3f4a — a dead grey dot on the bar ground
.hit--you #ff2fd6 with box-shadow:0 0 8px of the same colour; transition:background .1s fades it back
The one glow in the flat language, and it is earned. The LED is the only place a shadow means light rather than depth: it flashes on every note that arrives over MIDI, so it has to be legible out of the corner of an eye at 9px. It carries no border, no radius token and no hover — it is a readout that happens to be round, sitting inside the same .grp as #played.

Rules. A one-glyph toggle is the base button with its padding narrowed to 6px 9px and its type raised to 15px on the same fixed 16px line box — so it stays 30px tall, ends up about as wide, and never needs a width of its own. It takes the base states unchanged: #333947 on hover, amber on #14161a at 600 when on, opacity .45 when disabled. It is for a control whose meaning is already in the glyph; anything that needs a word gets a word. The LED is not this component and must never be confused with it: no border, no radius, no cursor, no click — a 9px dot that lights magenta and fades, and the only glow the language allows.
