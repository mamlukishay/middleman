Button

The flat control every bar, deck and sidebar is built from: a #2a2f3a face on a 1px --line border, 6px radius, the page font in a fixed 13/16 line box. The variants change the size, the padding and the ink — never the shape and never the height rule.

Base — 30px, the size everything else is measured against
restface #2a2f3a, border --line, 6px radius, 13/16 + 6px 12px padding = 30px
hoverface #333947. Nothing else moves — no border, no ink, no size
.tgl.onground and border --accent #e8b44a, ink #14161a, weight 600
disabledthe same face at opacity .45, cursor default. No colour changes
Mini — the looper and lesson small size
restface #22262f, 5px radius, 3px 8px padding, 11px, tabular figures = 24px
.mini.onamber ground and border, ink #14161a, 600 — the base on-state at the small size
hovernothing happens: button.mini's own face is written after button:hover
Start — the learn page's one big commitment
rest15px/700 on amber, ink #14161a, 11px 14px padding = 40px
hoveramber lifts to #f0c25e
.start.oninverted: running, it goes back to the grey face #2a2f3a on --line, ink --fg
The one inversion in the language. Everywhere else .on means amber; here the idle button is the amber one, because when it is the only thing to do it should look like it, and once it is running it should stop asking to be pressed. Note that .start.on is written after .start:hover, so the running button has no hover state at all.
Next — amber outline, filled when it is the next thing to do
restbase face, border and ink --accent, weight 600 — an outline, not a fill
.gofills: amber ground, ink #14161a. The border was already amber
Capture — an outline button carrying a glyph
restamber border and ink, 600, 9px 14px padding = 36px; flex row, 8px between glyph and word
hoverface #333947, the amber outline and ink unchanged

Rules. A button is one height: 30px, from font:13px/16px plus 6px of padding top and bottom plus the 1px border — the line box is fixed so the glyph in the label can never set the height. The radius is 6px, and only .mini departs from it, at 5px with its own smaller padding. Hover is a face change to #333947 and nothing else. The on-state is always --accent ground with #14161a ink at weight 600, on the base size and on .mini alike; the only exception is button.start, which runs the other way and turns grey when it is active. Disabled is opacity .45 — the colours stay exactly where they were, so a dead control reads as the same control faded, never as a different one.
