Transport

Play, Stop and Click: the first group in every bar, and the only controls that appear on more than one page. They are plain buttons — the group is made by markup, not by a component — and the only thing that separates an action from a toggle is whether the element carries .tgl.

.tgl is the whole difference. #play is a plain button on the practice page — it starts a track and hands control back — carries .tgl in the markup on learn, and is given .tgl from JS on the looper before the first sync. Same element, same id, three pages, and only the class says whether the button can light. .na is the only state that stacks: it sits on top of .on rather than replacing it, so the control still reads as switched on while saying it cannot act.

One group, 6px inside it. Each row is a real #bar, so the specimens get the app's own #bar .grp: 6px between the buttons that belong together, 14px before whatever comes next, and white-space:nowrap so a label can never break in two. Practice and looper carry all three; learn drops Stop, because a lesson is a loop you leave rather than a track you end. Nothing about the group is a component — it is a <span class="grp"> around plain buttons, and that is deliberate: the bar is assembled, not configured.

Rules. The transport is plain buttons at the one height, 6px apart, in the order Play, Stop, Click, first in the bar and never anywhere else. An action button (Stop) has rest, hover and disabled only. A toggle (Click, and Play where it can pause) adds .tgl and lights amber on #14161a at 600 — and a lit toggle no longer answers hover, which is how you can tell the state is held rather than hovered. A toggle that is on but powerless takes .na on top: opacity .45 and a strikethrough, never a colour change and never a disabled attribute, because the setting is still yours — it just has nothing to act on. Labels carry a leading glyph and change to name the next action, not the current one.
